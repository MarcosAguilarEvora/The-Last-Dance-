┌─ COMANDOS PRINCIPALES ────────────────────────────────────────────────────────┐
│                                                                                │
│ 1. COMPILAR (por defecto)                                                     │
│    mingw32-make                                                                │
│    mingw32-make all                                                            │
│                                                                                │
│ 2. EJECUTAR                                                                   │
│    bin\FutbolJuego.exe                                                         │
│                                                                                │
│ 3. COMPILAR + EJECUTAR (en una línea)                                         │
│    mingw32-make && bin\FutbolJuego.exe                                         │
│                                                                                │
│ 4. LIMPIAR TODO                                                               │
│    mingw32-make clean                                                          │
│    (Elimina: bin/ y obj/)                                                      │
│                                                                                │
│ 5. LIMPIAR SOLO OBJETOS                                                       │
│    mingw32-make clean-obj                                                      │
│    (Mantiene: bin/FutbolJuego.exe)                                             │
│                                                                                │
│ 6. LIMPIAR SOLO EJECUTABLE                                                    │
│    mingw32-make clean-bin                                                      │
│    (Mantiene: obj/*.o)                                                         │
│                                                                                │
│ 7. MOSTRAR INFORMACIÓN DEL PROYECTO                                           │
│    mingw32-make info                                                           │
│                                                                                │
│ 8. MOSTRAR AYUDA                                                              │
│    mingw32-make help                                                           │
│                                                                                │
└───────────────────────────────────────────────────────────────────────────────┘

┌─ CÓMO AGREGAR NUEVOS ARCHIVOS .cpp ───────────────────────────────────────────┐
│                                                                                │
│ 1. Crear el archivo en src/                                                   │
│    $ echo // nuevo > src/nuevaFuncion.cpp                                      │
│                                                                                │
│ 2. Crear el encabezado en include/                                            │
│    $ echo // nuevo > include/nuevaFuncion.hpp                                  │
│                                                                                │
│ 3. Incluir desde tu código                                                    │
│    #include "nuevaFuncion.hpp"                                                │
│                                                                                │
│ 4. Compilar (EL MAKEFILE LO DETECTA AUTOMÁTICAMENTE)                          │
│    $ mingw32-make                                                              │
│                                                                                │
│ El Makefile usa $(wildcard src/*.cpp) para detectar automáticamente            │
│ todos los archivos .cpp en el directorio src/                                 │
│                                                                                │
└───────────────────────────────────────────────────────────────────────────────┘

┌─ TROUBLESHOOTING ─────────────────────────────────────────────────────────────┐
│                                                                                │
│ ❌ "mingw32-make: command not found"                                          │
│    → Verifica que MinGW esté en tu PATH                                       │
│    → echo %PATH%                                                              │
│    → O usa: C:\msys64\mingw64\bin\mingw32-make.exe all                         │
│                                                                                │
│ ❌ "No rule to make target"                                                   │
│    → Verifica que src/main.cpp existe                                         │
│    → Verifica que include/ tiene los .hpp                                     │
│                                                                                │
│ ❌ El ejecutable no se crea                                                   │
│    → mingw32-make clean                                                       │
│    → mingw32-make -B (fuerza recompilación)                                    │
│                                                                                │
│ ❌ "Permission denied" al compilar                                            │
│    → Cierra el juego si está ejecutándose                                     │
│    → Verifica que bin/FutbolJuego.exe no esté abierto                         │
│                                                                                │
│ ❌ Cambios no se reflejan en la compilación                                   │
│    → mingw32-make clean                                                       │
│    → mingw32-make all                                                          │
│                                                                                │
